## Problem Statement

Build a **Task Management REST API** using **Node.js**, **Express.js**, and **MongoDB**.

The API must allow users to **create, read, update, delete, filter, search, sort, and paginate** tasks.

### Task Schema

| Field | Type | Description |
|:---|:---|:---|
| `title` | String | Task title *(required)* |
| `description` | String | Task description *(required)* |
| `status` | String | `pending` · `in-progress` · `completed` |
| `priority` | String | `low` · `medium` · `high` |
| `assignedTo` | String | Person assigned to the task |
| `dueDate` | Date | Task deadline |
| `createdAt` | Date | Auto-generated by Mongoose |
| `updatedAt` | Date | Auto-generated by Mongoose |

##  API Endpoints

> Implement **all** of the following endpoints to earn full marks.

---

### `A` &nbsp; Create Task &nbsp; — &nbsp; `POST /api/tasks` &nbsp; `[10 Marks]`

**Endpoint:**
```
POST /api/tasks
```

**Request Body:**
```json
{
  "title":       "Learn Node.js",
  "description": "Complete Express.js CRUD APIs",
  "status":      "pending",
  "priority":    "high",
  "assignedTo":  "Yogesh",
  "dueDate":     "2026-12-10"
}
```

**Requirements:**
- ✅ Create a new task and save it to MongoDB
- ✅ Validate required fields (`title`, `description`)
- ✅ `status` must be: `pending`, `in-progress`, or `completed` only
- ✅ `priority` must be: `low`, `medium`, or `high` only
- ✅ Return the created task with HTTP status **201**

---

### `B` &nbsp; Get All Tasks &nbsp; — &nbsp; `GET /api/tasks` &nbsp; `[10 Marks]`

**Endpoint:**
```
GET /api/tasks
```

**Requirements:**
- ✅ Fetch all tasks from MongoDB
- ✅ Return all available task records
- ✅ Return an appropriate response message if no tasks exist

##  Sorting & Pagination

---

### `J` &nbsp; Sort Tasks &nbsp; `[5 Marks]`

```
GET /api/tasks?sortBy=createdAt&order=asc
GET /api/tasks?sortBy=createdAt&order=desc
```

- ✅ Sort by `createdAt` field
- ✅ Support `asc` (ascending) and `desc` (descending) order

---

### `K` &nbsp; Pagination &nbsp; `[10 Marks]`

```
GET /api/tasks?page=1&limit=5
```

- ✅ Implement using `.skip()` and `.limit()`
- ✅ Default: `page = 1`, `limit = 10`
- ✅ Response must include `totalTasks`, `totalPages`, `currentPage`, `limit`

**Expected Response:**
```json
{
  "success":     true,
  "currentPage": 1,
  "totalPages":  5,
  "totalTasks":  25,
  "limit":       5,
  "data": [
    {
      "title":    "Learn Node.js",
      "status":   "pending",
      "priority": "high"
    }
  ]
}
```

##  Important Instructions

> Follow these rules — marks will be deducted for violations.

- ✅ Use **Express.js** to create REST APIs
- ✅ Use **MongoDB** and **Mongoose** for all database operations
- ✅ Use correct HTTP methods: `GET`, `POST`, `PUT`, `DELETE`
- ✅ Use `req.params` for route parameters (`:id`)
- ✅ Use `req.query` for filtering, searching, sorting, and pagination
- ✅ Use `req.body` for creating and updating records
- ✅ Handle all errors properly with meaningful messages
- ✅ Use meaningful HTTP status codes (`200`, `201`, `400`, `404`, `500`)
- ✅ **Do NOT** write all code inside `server.js`
- ✅ Test every endpoint using **Postman**
- ❌ Do NOT implement frontend or authentication
